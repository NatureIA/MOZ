# MOZ Driver — iOS
Aplicativo SwiftUI nativo para iOS 16 ou superior. Usa a API HTTPS de produção existente, autenticação do motorista por CPF e senha, sessão protegida no Keychain, demandas, etapas, notificações no aplicativo, comprovantes e Core Location. Não há botão de iniciar viagem: somente uma autorização positiva do backend permite iniciar GPS. Após ativação confirmada, coleta durante a viagem mesmo sem internet, com permissão do sistema e indicador de localização em segundo plano. Cada posição é gravada com ID e horário originais em arquivos privados protegidos; fotos são gravadas antes de confirmar o salvamento. Sincronização cronológica em lotes, com GPS antes de cada foto; comprovante da etapa final configurada para finalizar por POD interrompe a coleta local, mantendo o estado pendente até confirmação do servidor. A fila é separada por motorista, inclusive após logout. Dados pendentes de conferência não são apagados. O sistema de localização e o servidor continuam responsáveis por validar as evidências; GPS ausente não é inventado.

Build em GitHub Actions no macOS com XcodeGen, compilação para dispositivo sem assinatura e testes de persistência no simulador. O ZIP sem assinatura não é instalável em um iPhone. Para distribuição é necessário configurar conta/equipe Apple, identificador do aplicativo, certificados, provisionamento e TestFlight/App Store (ou outra modalidade autorizada). Nenhuma credencial Apple é incluída.

Limitações: localização em segundo plano depende das permissões, do iOS e da continuidade do processo; ativação de viagem com aplicativo totalmente fechado não é garantida. BGAppRefresh é oportunista e não garante horário de execução; sincroniza também ao abrir o aplicativo e durante a coleta autorizada. Cancelamento remoto não chega durante perda de conexão; o backend não incorpora posições de viagem encerrada. Após expiração de sessão, a fila é preservada até autenticação do mesmo motorista. Ações manuais de carga/descarga e ocorrência ainda exigem conexão, assim como cadastro e primeira ativação. Notificações são consultadas na API; APNs remoto não foi configurado. Testar em iPhones reais, inclusive tela bloqueada, modo avião, retorno de sinal e POD, antes da distribuição comercial.
